# EQ 与这套音频雷达的关系

## 一句话
EQ 能救"低频轰鸣把底噪抬高、脚步被压死"这一种情况；救不了"宽带噪声（风雨/音乐/语音）盖住脚步"。
对雷达本身，改分析频带 + 噪声门比外挂 EQ 更精确；对耳朵，外挂 EQ 才是唯一手段。

## 实测（DirectionEstimator，8ch，BL 声道 1.2kHz 瞬态脚步，全声道 80Hz 轰鸣）

| 条件 | 全带 60–12000 | 120–8000 | 150–8000 | 200–8000 |
|---|---|---|---|---|
| 轰鸣 .06 + 脚步 .05 | 0% | 0% | 12% | 12% |
| 轰鸣 .02 + 脚步 .05 | 0% | 12% | 12% | 12% |

- 12% = 脚步瞬态块占比（2/19 块），相当于每个脚步都检到了，其余时间安静。
- 低切 120 不够：FFT 分辨率 46.9Hz，120Hz 只比 80Hz 高 2.5 个 bin，汉宁窗泄漏仍压不住。
- 底噪若是宽带（风/雨/音乐/语音），削哪一段都同时削脚步，SNR 不变 —— EQ 无收益。

## 怎么用

### A. 外挂 EQ（作用于耳朵 + 雷达）
双击 `安装EQ.bat`（需管理员），脚本会：
1. 找 Equalizer APO 安装目录（没装会提示下载）
2. 备份 `config.txt`
3. 写入 `FPS_Footstep_7.1.txt` 并在 `config.txt` 追加一行 `Include:`
4. 之后去 Equalizer APO Configurator 勾选你那根 7.1 虚拟声卡，Restart audio service

卸载：双击 `卸载EQ.bat`。
只想先看看会做什么：`install_eq.ps1 -DryRun`。

曲线：Preamp −4 dB；HPQ 25/90 Hz；220 Hz −3 dB；1.2k +1.5 / 2.8k +3 / 4.5k +1.5；9k 高架 −4 dB。
**所有声道同一条曲线**，按声道分支会直接破坏方向判断。

### A2. 用软件里的多段 EQ（不打 EA 也能调）
托盘 → **EQ 分析频带 → 打开 EQ 窗口**，9 套场景预设一键套用（脚步增强 / 室内近战 / 草地沙地 /
雨雪 / 载具引擎 / 交火 / 耳机偏闷补偿…），也可以自己增删段。它只改检测权重，不改系统音频。

### B. 雷达内部频带（只影响检测，推荐）
默认已在 `CONFIG["band_low"] / ["band_high"] = 150 / 8000`，"中""高"预设自动带；
"低"预设保留全带（线索全，但容易被低频轰鸣压死）。运行中切换会清空底噪历史。

### C. 游戏内设置（优先级最高）
- 音频输出：7.1 / 家庭影院，不要"耳机 / HRTF"
- 关掉：夜间模式、动态范围压缩、响度均衡
- 音乐/语音压低，脚步/环境音拉高
